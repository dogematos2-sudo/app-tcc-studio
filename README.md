# app-tcc-studio
Assistente inteligente e gestor de TCC/TFG para estudantes de Arquitetura e Urbanismo. Automatiza pesquisas técnicas (NBR 15220 / NBR 9050), calcula índices urbanísticos, organiza pranchas A1, gera partido/memoriais com IA e funciona como PWA no celular.


# 🏛️ ArchTCC Studio - Gestor & IA de Arquitetura

O **ArchTCC Studio** é um aplicativo PWA desenvolvido para otimizar e automatizar a rotina de desenvolvimento do Trabalho de Conclusão de Curso (TCC/TFG) em Arquitetura e Urbanismo.

## 🚀 Funcionalidades Principais

- **⚡ Assistente de Pesquisa com IA:** Mapeamento automático de obras correlatas, diagnóstico bioclimático (NBR 15220), acessibilidade (NBR 9050) e pré-dimensionamento de programa de necessidades.
- 
- **📐 Organizador de Pranchas Técnicas:** Gerenciamento de folhas A0/A1, checklist de escalas e controle de plotagem.
- 
- **📊 Calculadora Urbanística & Quadro de Áreas:** Verificação de Taxa de Ocupação (T.O.), Coeficiente de Aproveitamento (C.A.) e cálculo automático de área útil e circulação.
- 
- **📝 Partido Arquitetônico & Tectônica:** Formulação assistida por IA para geração de conceitos formais, esquemas estruturais (MLC, concreto, aço) e memoriais descritivos.
- 
- **🎓 Simulador de Arguição de Banca:** Módulo interativo que simula perguntas técnicas da banca examinadora para treino de defesa oral.
- **📱 Suporte PWA (Mobile):** Funciona como aplicativo nativo em dispositivos iOS e Android com instalação direta da web.

## 🛠️ Tecnologias Utilizadas

- **Front-end:** React, TypeScript, Vite, Tailwind CSS
- **Inteligência Artificial:** Google Gemini API (`@google/genai`)
- **PWA:** Vite PWA Plugin, Web App Manifest, Service Workers
